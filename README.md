# TimoTime

Ewidencja czasu pracy Monorise w przeglądarce i na telefonie: start i stop pracy, przerwy, obecność na żywo, poprawki, wnioski urlopowe i raporty. Logowanie kontem Monorise przez MonoriseCore. Decyzje: ADR-0095 i ADR-0096 w repozytorium MonoriseDocumentation.

Pierwsza wersja powstaje w kolejnych pull requestach.
